## Setup
1. To setup this program, download the zip file and place the Stock.txt and UserAccounts.txt in the same file as phem.jar
2. Next, navigate to the folder in a terminal and type java -jar phem.jar
3. Finally, the program will begin and you will be prompted to select a user

## What does it do?
- The program allows admin roles to view all event details and add new events
- User roles are permitted to view some event details and buy tickets to events
- The program contains error-checking and safety features to prevent misuse
- The program then updates the text files appropriately
